## What works now

In the updated app, open **Settings â†’ Inspect project Â· local**. Enter a folder and click **Select read-only project**, then check **Allow local reads for this project view**. Search literal text, read an allowed relative file, view bounded pages and SHA-256 receipts, cancel a task or revoke reads. **Map this project** (`project.outline.v1`) adds a name-only inventory: suffix counts, recognized manifest names, and top-level folders. Selecting a folder does not enable file edits or command execution. Root changes/reconnect clear view consent.

Search and file pages use `project.search.v1` / `project.read.v1`. The map uses `project.outline.v1`. All three go through the existing broker gateway and Engine/Store workflow journal. Protected paths, reparse/symlink escapes, hardlinks, binary/invalid UTF-8, oversized files and recognized/configured secrets are withheld. Active work blocks project/workspace changes. Legacy workspace-root changes revoke project-read availability. Duplicate clicks are coalesced; explicit retries retain idempotency identity after an unknown submission result. Reconnect uses GET/event replay, never automatic resubmission. Unexpected error strings are not echoed.
