# Release / pull request gate

- [ ] No fake production features or misleading success states.
- [ ] Current phase acceptance criteria passed with logs/test output.
- [ ] Model eligibility verified; no paid fallback.
- [ ] Secrets never in frontend, Git or logs.
- [ ] Windows origin/session auth verified; tools start default-denied.
- [ ] Cancellation, worker failure, crash/restart and retry boundaries tested.
- [ ] Licensing/dependency scanning and pinned versions documented.
- [ ] Idle CPU, RAM, GPU profiled; regressed metrics documented.
- [ ] User-facing settings and limitations accurate.
- [ ] README, architecture and setup docs updated.
